# 🐶 Calculadora Infantil Bluey 🧮

Um aplicativo divertido e educativo de calculadora desenvolvido para crianças, inspirado no universo e nos personagens da adorável cadelinha **Bluey**. O objetivo do projeto é introduzir as crianças ao mundo da matemática básica de forma lúdica, intuitiva e bastante colorida.

---

## 🌟 Funcionalidades

- ➕ **Soma:** Operações de adição com feedback visual animado.
- ➖ **Subtração:** Exercícios e cálculos simples de subtração.
- ✖️ **Multiplicação:** Introdução à multiplicação com auxílio visual.
- ➗ **Divisão:** Conceitos primários de divisão para crianças.
- 🎨 **Interface Temática:** Design personalizado com elementos gráficos e cores vibrantes da Bluey.
- 🔊 **Interatividade:** Botões grandes e responsivos adaptados para o público infantil.

---

## 🛠️ Tecnologias Utilizadas

- **Plataforma:** Android Native
- **Linguagem:** Java / Kotlin
- **Interface:** XML Layouts com suporte a animações e imagens personalizadas
- **Assets:** Ilustrações e ícones customizados

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Android Studio instalado (versão recente)
- Dispositivo Android físico com modo de depuração ativado ou um emulador configurado

### Passo a Passo

1. **Clonar o Repositório:**
   ```bash
   git clone https://github.com/seu-usuario/calculadora-bluey.git
   ```

2. **Abrir no Android Studio:**
   - Inicie o Android Studio.
   - Selecione **Open an Existing Project** e escolha a pasta do projeto.

3. **Sincronizar o Gradle:**
   - Aguarde o término do download das dependências e sincronização do Gradle.

4. **Executar o App:**
   - Conecte seu dispositivo ou inicie um emulador.
   - Clique no botão **Run (▶)** no topo da IDE.
